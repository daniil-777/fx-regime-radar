FX Regime Radar · embeddable badge

Each badge below is one <script> tag. It reads the newest computed regime state from /api/regimes/{pair} on this origin and shows the regime word, the anomaly siren percentile and the change risk. No tracking; an optional ?partner= tag on the script URL is logged for attribution only.

<script src="https://YOUR-HOST/widget.js?partner=yourname" data-pair="EURUSD" async></script>

API docs: /docs · metrics: /metrics

Educational tool. Not investment advice.
